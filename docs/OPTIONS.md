# opencif options sheet

This sheet is generated by `tools/options_sheet.py` from `opencif/spec.py` (the schema, the allowed values, and the defaults), and `tests/test_options_sheet.py` fails if an option is undocumented or this file is stale.

## 1. What the generator needs

The two design targets are the size cutoff D and the filtrate fraction F. The other inputs are the fabrication context (process and chip) and the parts (layout, taper and center width, meander head, inlet, and outlet). The gap fraction f_gap and the row count N are outputs rather than inputs, except in reproduce mode, where a `reproduction` block may prescribe a paper's depicted head fractions and those rows are declared. On the kappa plateau, D and F are independent (App. A R13(c); App. B C8).

```python
import opencif
r = opencif.generate(4.0, 0.5, out='/tmp/cif')    # D = 4 um, F = 0.5; every other choice defaulted
r = opencif.generate(2.5, 0.6, process='dinh2024', chip=(25, 75), layout='serpentine',
                     taper=('constant_shear', 70, 50), meander='pack', inlet='filter', outlet='teardrop')
print(r.verdict, r.exit_code, r.dxf, r.figures)   # r.record is the full validation record
opencif.generate(4.0, 0.5, check_only=True)        # plan, gates, outline collisions; nothing written
```

```
python3 -m opencif generate 2.5 0.6 --process dinh2024 --chip 25x75 --layout serpentine \
        --taper constant_shear --width-in 70 --width-min 50 --meander pack --inlet filter --outlet teardrop
python3 -m opencif generate 4 0.5 --check                      # plan, gates, outline collisions; nothing written
python3 -m opencif generate 4 0.5 --set checks.cutoff_tolerance=0.02 --set physics.trim_F=true
python3 -m opencif build runs/<name>/<name>_spec.yaml           # rebuild from the spec generate() wrote
```

Every part argument also takes a dict of its section's keys (section 3), for example `meander={'style': 'arms', 'arms': 3, 'seal': 'require'}`. A `process=` dict replaces the named process entirely, so unset post sizes then take the spec defaults, 25 and 50 um. `overrides=` merges a dict into any section last, and on the command line `--set section.key=value` does the same (the value is read as YAML). generate() writes the spec that it built to `<out>/<name>_spec.yaml`.

## 3. Every key

The types and defaults are the code's. "Verified by" names the record check (`assessment.checks`) or field (`validation.*`) that tests the choice on the drawn mask. The symbols follow the frozen glossary. Note that `post_length_um` is the glossary's g_p, "post width", along the flow, and `post_width_um` is its l_g, "link length", across the flow. Captions, documents, and the dissertation use the glossary's words (g_p post width along the flow, ℓ_g link length across it, Λ row pitch), whereas the YAML keys are historical.

### `name`: the device name, which names the files in runs/<name>/  (generate: `name`)

### `description`: free text, copied to the record  (generate: `description`)

### `targets`: the two design targets (the only targets, whereas the depth, gap, posts, flow, and fluid are model inputs)  (generate: `cutoff_um, filtrate_fraction, filtrate_to_retentate_ratio`)

| key | type | allowed | default | meaning | symbol | verified by |
|---|---|---|---|---|---|---|
| `cutoff_um` | float |  | **required** | the size cutoff D, above which rigid spheres stay in the center channel; it sets the lamina delta* = D/kappa_g | D = kappa_g delta* (App. A R13(a); implementers step 2) | Q2 "cutoff D at every gap"; validation.realised_cutoff |
| `filtrate_fraction` | float |  | **required** | the filtrate fraction F, the fraction of fluid sent to the filtrate (in App. B, "yield" = F) | F (App. A R10, eq. 67) | Q2 "filtrate fraction F"; validation.network.F_as_drawn |
| `filtrate_to_retentate_ratio` | float |  | instead of F | an alternative to F, the flow ratio r = F/(1-F), so that F = r/(1+r). It is not the glossary's FR (Inglis and Herman's filtration ratio) | F/(1-F) | as F |

### `process`: the fabrication process (depth, gap, posts, feature floor, and aspect-ratio limit)  (generate: `process`)

| key | type | allowed | default | meaning | symbol | verified by |
|---|---|---|---|---|---|---|
| `depth_um` | float |  | **required** | channel depth h (every duct is h deep) | h | enters every resistance, and is not drawn because a mask is 2-D |
| `gap_um` | float |  | **required** | gap width G between posts, along the flow | G (glossary: link width) | measured gap openings (Q1) |
| `post_length_um` | float |  | `25.0` | post size along the flow, which is the wall segment between gaps; the row pitch is Lambda = G + this | g_p (glossary: "post width") | drawn, and the row pitch enters Q1 |
| `post_width_um` | float |  | `50.0` | post size across the flow, which is the wall that the gap crosses (the gap length) | l_g (glossary: "link length") | taken from the design rather than measured (see the record notes) |
| `wall_along_flow_um` | float |  |  | the glossary's name for `post_length_um` (g_p, "post width", the post along the flow), accepted as an alias since rc7; given with `post_length_um`, the two must agree | g_p | as post_length_um (the record keeps post_length_um) |
| `wall_cross_flow_um` | float |  |  | the glossary's name for `post_width_um` (l_g, "link length", the wall that the gap crosses), accepted as an alias since rc7; given with `post_width_um`, the two must agree | l_g | as post_width_um (the record keeps post_width_um) |
| `min_feature_um` | float |  | **required** | the process floor, which is the narrowest channel or wall that can be made | F_min | "DRC at the process floor", "side channels continuous", "no intersections" |
| `min_radius_um` | float |  | derived: min(4.5, 0.25 x min_feature) | the smallest inner-corner radius that the process makes | R_min (glossary, Validity-Envelope and External Inputs: external) | "corner radius" |
| `fillet_um` | float |  | derived: min(5, 0.4 x the narrowest drawn feature (min_feature, gap and post length; with a head also the meander wall, channel, arm and narrow widths), 0.3 x the narrowest head unit (channel, arm, narrow width)) | fillet radius (closing, then opening), drawn over only two zones, the inlet with the meander head, and the outlet (its lead steps and port necks). | `gap_entrance_c` | float |  | `1.0` | gap entrance coefficient in R_gap = r(G) [l_g + c_ent D_h] | c_ent (glossary, Validity-Envelope and External Inputs: external) | a design value (future work: 3-D calibration) |
| `aspect_ratio_max` | float |  | `10.0` | the deepest channel that the process makes, as depth over width (AR_max). CIF_v2's floor w_min = max(min_feature, depth/AR_max) is a gate, checked before drawing, on the gap, the meander channel, every center width, and every straight side channel (spec v5 G7; G11 would fold a narrower side channel, which opencif does not draw), and on the drawn mask (the narrowest CIF channel's depth/width). Strict mode refuses or fails, whereas evaluate and reproduce modes report (LIMITATIONS 7). The default is CIF_v2's 10 (Gifford 2014 p. 4503 assumes "a 10 : 1 aspect ratio limitation"), and a finer process is a stated capability rather than a foundry fact | AR_max (glossary, Validity-Envelope and External Inputs: external); w_min (spec v5 sec. 18) | "aspect ratio of the narrowest CIF channel" (a pass condition in strict mode, reported in evaluate and reproduce modes); assessment.over_aspect_ratio |

## 4. Combination rules (refused with a SpecError, exit 6)

- targets: `cutoff_um` > 0; `filtrate_fraction` in (0, 1), or `filtrate_to_retentate_ratio` > 0 (not both, unless equal); `f_gap` is never a target (a `targets.f_gap` key is refused)
- the lamina delta* = D/kappa_g must be less than half of `width_in_um` and of `width_min_um` (App. A, implementers step 3)
- a design whose closure has no solution (f_gap far above the calibrated range) is a spec error rather than a crash
- `layout.legs`: 1 for linear; >= 2 for paperclip; odd and >= 3 for serpentine; or `auto`
- `outlet.style: ring` only with linear and paperclip layouts
- `inlet.style: dinh_filter` only with `meander.style: arms`, `arms: 3`
- `meander.seal: allow` is not accepted in strict mode
- `start.style: floor` only without a meander head; `start.side_width_um` only with `floor`
- `centre_channel.width_min_um` only with `constant_shear` (and required there)
- `meander.rectilinear_rows` >= 1
- `process.post_width_um` (across the flow) >= `post_length_um` (along it)
- `checks.cutoff_tolerance` in (0, 0.05]; `checks.F_tolerance` in (0, 0.01]
- `physics.bend_model: none` not in strict mode
- a `reproduction` block, `meander.transition: paper` and the other reproduction-only options need `gates.mode: reproduce`
- a sealed start without a head must not draw a first side channel below the floor (use a head, `start: floor`, or a finer process)
- unknown keys and unknown values are refused

## 6. Exit codes

| code | meaning |
|---|---|
| 0 | PASS (new design) or REPRODUCED (preset) |
| 2 | FAIL: a hard check failed on the drawn mask (in strict mode this includes the aspect ratio of the narrowest CIF channel, whereas the chip area is reported and is never a failure). Since rc7, the photomask is kept for diagnosis as `<name>_FAILED.dxf` and never under the deliverable name |
| 3 | outside the validity envelope: in evaluate or reproduce mode, where the design is drawn and measured (build), or planned and outlined in memory with nothing written (`opencif check`, `generate(check_only=True)` / `generate --check`); and in strict mode when a gate fails only on the drawn mask after the plan passed it (docs/LIMITATIONS.md item 31) |
| 4 | INCOMPLETE (for example, the DRC was not run) |
| 5 | REFUSED, with no mask written. Strict mode refuses before drawing outside the envelope or on a failed pre-flight gate (a meander head's GS/G outside gamma_GS [1.4, 1.5], or a channel below w_min). Any mode refuses a head that cannot seal gap 1 under `seal: require`, an outlet that cannot be planned at any leg count that the layout tries (found before drawing, or while fitting or drawing), or, since rc7, parts of the drawn outline that collide (a part closer than the floor to one that it is not joined to, outlet ports not separated, or an outlet port within 2 mm of the inlet port). The collisions are found on the outline in memory before the photomask is written, and they are reported with the parts, the remedies, and a figure. The record gives the numbers and the cutoff band, which on the plateau is the kappa_g interval x delta* and below it App. B C7's plateau-anchored band rather than the self-consistent cutoff, which can lie lower (C7 CQ3) |
| 6 | SPEC ERROR (command line) for an invalid or unplannable spec, for which generate() raises opencif.spec.SpecError |
| 1 | an unexpected exception (no record written) |
